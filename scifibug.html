Summary

This project was intended to be an exercise to learn the program Zbrush. Students were allowed to choose any object in order to replicate OR create a semi-realistic object within ZBrush. By using images of Stag beetles as well as taking reference from the video game Unfortunate Spacemen, a stylized alien beetle was concepted. The color palette was influenced by Eygptian Scarab beetles.
